# Personal Links

A minimal, responsive, icon-only personal link page with an original red-and-black superhero-inspired visual treatment.

## Links

- TryHackMe
- Portfolio
- Email
- LinkedIn

## Deploy
This repository uses GitHub Actions to publish the root directory to GitHub Pages on every push to `main`.

Enable GitHub Pages in **Settings → Pages** with **GitHub Actions** as the build and deployment source if it is not already enabled.
